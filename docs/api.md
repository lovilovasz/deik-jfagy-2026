# API reference

Base URL: `http://localhost:8080`. All bodies are JSON. Interactive docs: `/swagger-ui.html`.

## Persons – `/api/persons`

| Method | Path | Description | Success | Errors |
| --- | --- | --- | --- | --- |
| POST | `/api/persons` | Create a person | 201 | 400 validation, 409 email in use |
| GET | `/api/persons` | List all persons | 200 | – |
| GET | `/api/persons/{id}` | Get one person | 200 | 404 |
| PUT | `/api/persons/{id}` | Update a person | 200 | 400, 404, 409 |
| DELETE | `/api/persons/{id}` | Delete person **and their todos** | 204 | 404 |

Request (`PersonRequest`):

```json
{ "name": "Ada", "email": "ada@example.com" }
```

`name` must not be blank; `email` must be a non-blank valid address and unique.

Response (`PersonResponse`):

```json
{ "id": 1, "name": "Ada", "email": "ada@example.com" }
```

## Todos – `/api/todos`

| Method | Path | Description | Success | Errors |
| --- | --- | --- | --- | --- |
| POST | `/api/todos` | Create a todo for a person | 201 | 400, 404 person not found |
| GET | `/api/todos` | List todos; optional `?personId=` filter | 200 | – |
| GET | `/api/todos/{id}` | Get one todo | 200 | 404 |
| PUT | `/api/todos/{id}` | Update a todo (can reassign person) | 200 | 400, 404 |
| DELETE | `/api/todos/{id}` | Delete a todo | 204 | 404 |

Request (`TodoRequest`):

```json
{ "title": "Write docs", "description": "optional", "completed": false, "personId": 1 }
```

`title` must not be blank, `personId` is required, `completed` is optional (defaults to `false`).

Response (`TodoResponse`):

```json
{ "id": 1, "title": "Write docs", "description": "optional", "completed": false, "personId": 1 }
```

## Error format

Errors use RFC 7807 `ProblemDetail`:

```json
{
  "type": "about:blank",
  "title": "Not Found",
  "status": 404,
  "detail": "Person not found: 42",
  "instance": "/api/persons/42"
}
```

## OpenAPI

- Live spec: `GET /v3/api-docs` (pretty-printed), UI at `/swagger-ui.html`.
- Exported spec: [`openapi/openapi.json`](../openapi/openapi.json), regenerated by
  `OpenApiSpecTests` every time `./mvnw test` (or `verify`) runs. Commit the updated file after API
  changes; it is meant for generating a frontend client.
- Metadata (title "Todo API", version "v1") lives in `config/OpenApiConfig`; per-operation docs are
  annotations on the controllers.
